# Roadmap

## Status model

- **Planned:** scoped or proposed, with no implementation evidence yet.
- **In Progress:** active work exists but is not validated.
- **Validated:** acceptance criteria and supporting evidence are documented.
- **Published:** validated work has passed a publication and privacy review.

Only the repository foundation is currently in progress.

| Area | Status | Evidence required for progression |
|---|---|---|
| Repository foundation and governance | In Progress | Phase report, structural validation, and owner review |
| Documentation website | Planned | Local build, link review, and approved publication workflow |
| Manual segmentation case study | Planned | Public/synthetic dataset, method, QC, and documented results |
| Semi-automatic segmentation | Planned | Reproducible workflow and comparison with defined reference |
| Automatic segmentation | Planned | Versioned pipeline, evaluation protocol, and limitations |
| Quantitative measurements | Planned | Units, methods, verification, and uncertainty documentation |
| 3D mesh and STL workflow | Planned | Reproducible exports, scale checks, and mesh QC |
| Radiomics workflow | Planned | IBSI-aware settings, provenance, stability checks, and results |
| Python package and CLI | Planned | Tests, documentation, and versioned release criteria |
| Deep learning foundations | Planned | Dataset governance, experiment tracking, and evaluation plan |
| Medical AI model evaluation | Planned | Defined task, baselines, metrics, bias and limitation review |
| Centerline workflows | Planned | Reproducible extraction and anatomical quality checks |
| Digital twins | Planned | Defined use case, assumptions, validation strategy, and evidence |
| Clinical research workflows | Planned | Governance mapping and approved non-clinical demonstration |
| Scientific publications | Planned | Accepted or publicly available publication record |
| International portfolio website | Planned | Approved content, accessibility review, and public deployment |

## Phase sequence

1. Foundation and governance
2. Case schema and safe automation
3. Documentation website and quality gates
4. First public or synthetic case
5. Quantitative imaging and radiomics foundations
6. Medical AI and advanced 3D workflows
