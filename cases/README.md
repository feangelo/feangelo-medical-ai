# Cases

Only synthetic, open-dataset, or public cases may be prepared here. Start from `Case_Template/`, keep the mandatory data classification, and complete the governance and publication checklists.

No case study has been published yet.

Some template directories are reserved for later stages of the learning roadmap. Their presence defines a stable long-term structure; it does not indicate that the corresponding analysis, model, or deliverable has already been produced. Each reserved directory contains a scope note when additional clarification is necessary.
