# Radiomics

This directory is intentionally reserved for future radiomics work associated with a documented case.

It will be populated only after the relevant concepts, preprocessing requirements, feature definitions, software configuration, and reproducibility limitations have been studied and applied in a reviewable exercise. Any future material must identify its data source, parameters, software version, quality controls, and limitations.

The presence of this directory does not indicate current proficiency, completed analysis, validated results, or clinical applicability. FAMAI Lab follows a progressive learning roadmap and records work only when supporting evidence is available.
