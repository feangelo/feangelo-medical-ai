# Security and Privacy Policy

## Supported versions

FAMAI Lab has not published a stable release. Security fixes currently apply to the latest state of the default branch after review.

## Prohibited content

Never commit, upload, attach, or paste:

- private clinical DICOM or other clinical imaging data;
- protected health information or personally identifiable information;
- re-identification keys or linkage tables;
- credentials, API tokens, private keys, or secrets;
- restricted datasets without explicit redistribution permission.

Only `synthetic`, `open-dataset`, or `public` cases are eligible, and every case requires a manual privacy and licensing review.

## Reporting a vulnerability or privacy incident

Do not open a public issue containing sensitive details. Use GitHub's private vulnerability reporting feature when it becomes available for the repository. Until a verified private contact method is published, retain the sensitive material and provide only a non-sensitive request for a private channel.

If sensitive data are discovered locally, stop processing them. Do not copy, move, rename, delete, or publish them as part of an automated cleanup. Notify the repository owner and follow the applicable institutional incident process.

## Clinical safety

Content in this repository is learning-oriented and experimental. It must not be used for diagnosis, treatment, patient management, or clinical deployment without independent validation, quality management, cybersecurity review, and applicable regulatory authorization.
